# CourtWale

**CourtWale** is a desktop document automation tool designed to help search, edit, and generate legal and administrative formats (such as notices, summons, and case documents) quickly, supporting **DOCX / ODT**, **DOC**, **PDF**, **JPEG**, and **JPG** outputs.

---

## Key Features
- **Multi-Language Interface:** Supports **ગુજરાતી (Gujarati)**, **हिन्दी (Hindi)**, and **English**.
- **Format Search & Live Editor:** Quickly find formats, edit text directly without altering original templates, adjust alignment (Left / Center / Right) and font size, and insert blank lines (`____`).
- **Case & Office Details:** Add Case No, Police Station, and FIR No to organize output files automatically or save to a custom location.
- **Multiple Output Formats:** Export documents as `DOCX / ODT`, `DOC`, `PDF`, `JPEG`, or `JPG`.

---

## How to Use
1. Open **CourtWale** (or run `smart_legal_tool.py` / `CourtWale.exe`).
2. Select your preferred language from the top bar.
3. Search and select a format, then edit or fill in details as needed.
4. Choose your desired output format (`DOCX / ODT`, `DOC`, `PDF`, `JPEG`, or `JPG`) and click **Save** or **Generate**.
